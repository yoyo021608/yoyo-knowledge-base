# 项目收尾优化项

本文件只记录不影响当前功能验收、但应在项目收尾阶段统一处理的实现优化。产品功能、模块职责和数据流仍以现有设计文档为准。

## 任务执行链统一

- 文档录入和编辑目前既写入持久化索引任务，又立即同步刷新索引。收尾时统一为“事务内排队、后台执行、前端查询状态”，避免接口等待 Embedding 和重复执行路径。
- Agent 提问和继续运行目前由 HTTP `BackgroundTasks` 启动。收尾时改为由应用生命周期内的统一执行器领取持久化 Run，controller 只负责接收请求和协调公开接口。
- Redis 任务队列已经由 infra 装配，但尚未接入业务任务。收尾时将它用于任务唤醒和重试，数据库继续保存任务与 Run 的最终状态，避免 Redis 成为核心数据源。

## 验收补充

- 当前 `tests/e2e/test_mvp_flow.py` 是使用 SQLite 和确定性模型替身的跨模块业务集成测试。收尾时另补使用正式 lifespan、PostgreSQL、Redis 和后台 Worker 的运行环境验收。
